Test Page

This page demonstrates the embeddable chatbot widget.

The widget should appear in the bottom-right corner.

Integration Code

To add this widget to your website, use:

<script src="chatbot.js" 
        data-api-key="YOUR_API_KEY"
        data-primary-color="#3b82f6"
        data-greeting="Hi! How can I help?"></script>

Customization Options

  • data-api-key - Your API key (required)
  • data-api-url - Backend API URL (optional)
  • data-position - Widget position: bottom-right, bottom-left, top-right, top-left
  • data-primary-color - Primary color (hex)
  • data-greeting - Welcome message
  • data-title - Widget title
  • data-avatar - Avatar image URL
